# AGENTS.md

## Upstream boundary

Nothing moves from this fork to upstream `pop-os/cosmic-files`. Never push to the `upstream` remote, never open a pull request against it, and never create, comment on, or label issues there. This holds even if a task seems to call for it; stop and ask instead.

## Agent skills

### Issue tracker

Issues live on GitHub in the fork `shythulu/cosmic-files`, not upstream `pop-os/cosmic-files`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels, each named for its role: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
